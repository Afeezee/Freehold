Setting up

Three things, then you are protected.

  1. 1

    Save your encryption key

    This file is the only thing that can read your backups. If it is lost, nobody can recover them — not us, not anyone. Copy it somewhere separate from this computer: a USB stick, a password manager, or print it.

  2. 2

    Choose where backups are kept

    A second disk or USB drive is the simplest. Online storage works too — your files are scrambled before they leave this computer, so the provider cannot read them.

    Pick a folder to protect

    Start with the one that would hurt most to lose. You can add more later.
