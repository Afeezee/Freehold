# The Freehold website

A static marketing and download page. Next.js, deployed on Vercel.

```bash
cd web
npm install
npm run dev      # http://localhost:3000
npm run build
```

## Deploying

On [vercel.com](https://vercel.com), import the repository and set
**Root Directory** to `web`. Everything else is detected. No environment
variables are needed, because the site has no backend.

Pushing to `main` deploys; opening a pull request gives a preview URL.

## What this site is, and is not

It is a page that explains the product and links to the downloads on GitHub
Releases. Every route is statically rendered at build time.

**It has no accounts, no database and no API.** That is a product decision
rather than an omission. Freehold's guarantee is that files are encrypted on
the owner's machine with a key that never leaves it; a server offering
"sign in and back up" would have to hold either that key or the files, which
would remove the guarantee entirely. The page says so plainly rather than
implying a service that does not exist.

If a browser-based client is ever added, it has to work the same way: the
key stays in the browser, requests go straight from the browser to the
person's own storage, and the Vercel deployment serves static files and
nothing else.

## Files

```
app/layout.tsx    metadata, Open Graph, icons, theme colour
app/page.tsx      the whole page
app/globals.css   design tokens shared with the desktop interface
components/Mark.tsx   the logo, drawn rather than imported
public/           icons and the social card, generated by tools/brand.py
postcss.config.mjs    deliberately empty; see the comment inside
```

Brand assets are generated, not hand-exported. To change the logo, edit
`tools/brand.py` in the repository root, run it, and copy the results into
`public/`.
